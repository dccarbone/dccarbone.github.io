herdr-ui
see every agent. answer the one that is blocked.

A window for herdr. It lists your spaces and agents, shows which one needs you, and lets you answer it from a browser or a native macOS app.

Download for macOS (.dmg)

Apple Silicon and Intel · macOS · needs herdr installed

Needs you

A blocked agent shows its last lines and the keys that answer it. Answer without opening its terminal.

Dock badge

The Dock icon counts blocked agents and bounces when one needs you.

Notifications

A native notification names the space and the agent that blocked or finished.

Spaces

Collapse a space and all its agents fold with it. Pin an agent to keep it in the overview.

Install

  1. Open the .dmg and drag herdr-ui to Applications.
  2. The app is not notarized. The first time, right-click it and choose Open. Or run xattr -cr /Applications/herdr-ui.app.
  3. Allow notifications in System Settings. The settings dialog in the app has a test button.

The app tells you in the footer when a newer version is out.
