Know without looking

The macOS app tells you when an agent needs you, even with the window in the background.

  • Native notifications. Each one names the space and the agent that blocked or finished.
  • Dock badge. The icon counts the blocked agents. The number drops as you answer them.
  • Dock bounce. The icon bounces when an agent blocks.
  • Your call. Turn off the finished notifications in settings. A test button checks it all works.

Seamless with herdr, better to look at

herdr-ui reads your herdr session as it is. Nothing to configure.

Same session

Talks to herdr through its CLI and socket. Your spaces, tabs and agents show up as they are.

Browser or app

One Go binary serves the UI. Use it in the browser, or as the macOS app.

Local only

It listens on 127.0.0.1. Nothing leaves your machine.

Update notice

The app footer tells you when a newer version is out.

Install in three steps

1
Drag to Applications

Open the .dmg and drag herdr-ui to Applications. It runs on Apple Silicon and Intel.

2
Open it

Double-click herdr-ui in Applications. The app is signed and notarized by Apple, so it opens like any other app.

3
Allow notifications

Turn them on in System Settings, so the badge and the alerts work. Settings in the app has a test button.

See every agent at a glance

Download herdr-ui and open it next to herdr. All screenshots on this page use sample data.
